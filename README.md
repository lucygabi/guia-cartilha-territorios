# Guia Cartilha Territórios

**Guia de Homologações, Revalidações e Reconfigurações Territoriais**

Ministério do Desenvolvimento Agrário e Agricultura Familiar — Secretaria de Governança Fundiária, Desenvolvimento Territorial e Socioambiental.

## Como usar

1. Abra o arquivo `Guia_Territorios_Diagramado.html` no navegador (Chrome, Edge, Firefox)
2. Use a barra de ferramentas no topo para editar textos, trocar imagens, ajustar espaçamentos
3. Clique no botão **? Ajuda** para ver o guia completo de edição
4. Salve com **Ctrl+S** ou clique em **Salvar**
5. Para gerar PDF, clique em **PDF** e escolha "Salvar como PDF"

## Funcionalidades do Editor

- Edição direta de textos no navegador
- Troca de imagens (clique na imagem)
- Formatação: negrito, itálico, sublinhado, cores, fontes, tamanhos
- Alinhamento e espaçamento de parágrafos
- Modo Contínuo (remove quebras de página para edição fluida)
- Inserir/excluir blocos e parágrafos
- Exportar como HTML editável ou PDF
- Funciona 100% offline, sem necessidade de servidor
